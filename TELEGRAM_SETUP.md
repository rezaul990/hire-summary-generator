# Telegram Integration Setup Guide

This guide will help you set up Telegram notifications for the Collection Summary app.

## Features

1. **Usage Tracking**: Automatically sends a notification to Telegram every time a user uploads an Excel file
2. **Tangail Area Report**: Automatically sends a detailed report of Tangail area performance including:
   - Summary totals (Target vs Achieved)
   - Percentage achievements
   - Overdue statistics
   - Individual plaza details

## Setup Instructions

### Step 1: Create a Telegram Bot

1. Open Telegram and search for `@BotFather`
2. Start a chat and send `/newbot`
3. Follow the instructions to create your bot:
   - Choose a name for your bot (e.g., "Collection Analytics Bot")
   - Choose a username (must end with 'bot', e.g., "collection_analytics_bot")
4. BotFather will give you a **Bot Token** - save this token (looks like: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Step 2: Get Your Chat ID

**Method 1: Using IDBot**
1. Search for `@myidbot` in Telegram
2. Start a chat and send `/getid`
3. The bot will reply with your Chat ID (looks like: `123456789`)

**Method 2: Using your bot**
1. Start a chat with your newly created bot
2. Send any message to the bot
3. Open this URL in your browser (replace `YOUR_BOT_TOKEN` with your actual token):
   ```
   https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates
   ```
4. Look for `"chat":{"id":123456789}` in the response - that's your Chat ID

### Step 3: Configure the App

1. Open the file `src/utils/telegram.js`
2. Replace the placeholder values:
   ```javascript
   const TELEGRAM_BOT_TOKEN = 'YOUR_BOT_TOKEN_HERE'; // Replace with your bot token
   const TELEGRAM_CHAT_ID = 'YOUR_CHAT_ID_HERE'; // Replace with your chat ID
   ```

   Example:
   ```javascript
   const TELEGRAM_BOT_TOKEN = '123456789:ABCdefGHIjklMNOpqrsTUVwxyz';
   const TELEGRAM_CHAT_ID = '987654321';
   ```

3. Save the file

### Step 4: Test the Integration

1. Run your app: `npm start`
2. Upload an Excel file
3. Check your Telegram chat - you should receive:
   - A usage tracking notification
   - A Tangail area report (if Tangail data exists in the file)

## Troubleshooting

### Messages not being sent?

1. **Check Bot Token**: Make sure you copied the entire token from BotFather
2. **Check Chat ID**: Verify your Chat ID is correct
3. **Start the bot**: Make sure you've sent at least one message to your bot
4. **Check console**: Open browser DevTools and check for error messages
5. **CORS issues**: If deploying to production, ensure your hosting allows external API calls

### Only usage tracking works, but no Tangail report?

- The Tangail report only sends if there's data with "Tangail" in the Area name
- Check your Excel file to ensure Tangail area data exists
- Check the browser console for any errors

## Privacy & Security Notes

⚠️ **Important Security Considerations:**

1. **Never commit your Bot Token to Git**: Add `telegram.js` to `.gitignore` or use environment variables
2. **Use Environment Variables** (Recommended for production):
   ```javascript
   const TELEGRAM_BOT_TOKEN = process.env.REACT_APP_TELEGRAM_BOT_TOKEN;
   const TELEGRAM_CHAT_ID = process.env.REACT_APP_TELEGRAM_CHAT_ID;
   ```
   
   Then create a `.env` file:
   ```
   REACT_APP_TELEGRAM_BOT_TOKEN=your_bot_token_here
   REACT_APP_TELEGRAM_CHAT_ID=your_chat_id_here
   ```

3. **Bot Token is sensitive**: Anyone with your bot token can send messages as your bot
4. **Chat ID is personal**: Keep your Chat ID private

## Customization

### Change notification format
Edit the message templates in `src/utils/telegram.js`:
- `trackFileUpload()` - for usage tracking messages
- `sendTangailReport()` - for Tangail area reports

### Add more area reports
You can create similar functions for other areas:
```javascript
export const sendDhakaReport = async (areaWiseData) => {
  const dhakaData = areaWiseData.filter(
    row => row.Area && row.Area.toLowerCase().includes('dhaka') && !row.isGrandTotal
  );
  // ... similar logic
};
```

### Disable notifications
To temporarily disable notifications, comment out the call in `App.js`:
```javascript
// sendUploadNotification(areaWiseSummary).catch(err => {
//   console.error('Telegram notification failed:', err);
// });
```
